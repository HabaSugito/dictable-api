Dictable API is a menu bar app that serves Apple's on-device speech model over an OpenAI-compatible HTTP API and live WebSocket streaming. Free, offline, and private: audio never leaves your Mac.

Dictable API は、macOS 標準のオンデバイス音声認識を OpenAI 互換の HTTP API と WebSocket のリアルタイム配信 で使えるようにするメニューバーアプリです。無料・オフラインで動き、音声は Mac の外に出ません。

FEATURES

Everything the OS can hear, available to any tool. OS の音声認識を、どんなツールからでも。

macOS 26 ships a fast, accurate on-device speech model, but only Swift apps can use it. Dictable API makes it available to Python, JavaScript, curl, browser extensions, and anything else that speaks HTTP. macOS 26 には高速で正確なオンデバイス音声認識が入っていますが、使えるのは Swift で作ったアプリだけです。Dictable API を使えば、Python・JavaScript・curl・ブラウザ拡張など、HTTP を話せるものなら何からでも使えます。

Drop-in OpenAI APIOpenAI API と互換

Same request format as /v1/audio/transcriptions. Change base_url and existing code keeps working./v1/audio/transcriptions と同じ形式です。base_url を変えるだけで既存のコードが動きます。

Live streamingリアルタイム配信

Send PCM over a WebSocket. Get partial text while people talk, and final sentences with timestamps.PCM を WebSocket で送ると、話している途中の文字と、時刻付きの確定した文が返ってきます。

Private and offlineプライベート・オフライン

Recognition runs on your Mac's Neural Engine. Meetings and voice notes never touch a cloud API.認識は Mac の中で行われます。会議の音声やメモがクラウドに送られることはありません。

Subtitles included字幕形式に対応

json, text, verbose_json with segments, srt, and vtt, all ready for video editors.json・text・区間付きの verbose_json・srt・vtt を出力できます。動画編集にもそのまま使えます。

Safe on localhostlocalhost でも安全

Binds to 127.0.0.1 only, blocks DNS rebinding, and refuses requests from websites you happen to have open.127.0.0.1 だけで待ち受け、DNS リバインディングを防ぎ、閲覧中の Web サイトからのアクセスを拒否します。

Lives in your menu barメニューバーに常駐

Copy the endpoints, watch live activity, change the port, and start automatically at login.接続先のコピー、処理の様子の確認、ポートの変更、ログイン時の自動起動ができます。

USE CASES

What you can build with it こんなアプリが作れます

Dictable API handles the hard part, turning speech into text fast and on-device, so your app can focus on what to do with the words. 音声を速く、Mac の中だけで文字にする部分は Dictable API が受け持ちます。アプリは、その文字をどう使うかに集中できます。

Real-time translationリアルタイム翻訳

Caption a video call, webinar, or YouTube video in another language as people speak. Each sentence is final about 0.2 s after it ends, so translations follow the speaker closely. ビデオ会議・ウェビナー・YouTube の音声を、話しているそばから別の言語の字幕にできます。文が終わってから約 0.2 秒で確定するので、訳も話し手にぴったりついていきます。

Tab / mic audioタブ・マイクの音声→ Dictable API ws→ Translation model翻訳モデル→ Live subtitles字幕
  • Show partial text while people talk, then swap in the translation per sentence.話している途中の文字を先に出し、文ごとに訳へ差し替える。
  • Pair it with a local translation model (e.g. PLaMo Translate via llama.cpp) to stay fully offline.ローカルの翻訳モデル（例: llama.cpp で動かす PLaMo Translate）と組み合わせれば、すべてオフラインで完結。
  • Browser extensions can connect directly: extension origins are allowed by default.ブラウザ拡張から直接つなげられます（拡張機能からの接続は最初から許可）。

Meeting notes and minutes議事録アプリ

Turn meetings, interviews, and lectures into timestamped transcripts, then summarize them into minutes, without sending confidential audio to a cloud service. 会議・インタビュー・講義を時刻付きの文字起こしにし、要約して議事録にできます。社外秘の音声をクラウドに送る必要はありません。

Recording or live audio録音・ライブ音声→ Dictable API http / ws→ Summarizing LLM要約用の LLM→ Minutes議事録
  • verbose_json gives sentence timestamps for jumping back to any moment.verbose_json で文ごとの時刻が取れるので、どの発言にもすぐ戻れる。
  • Export srt / vtt to attach captions to the recording.srt・vtt で書き出せば、録画にそのまま字幕を付けられる。
  • Uses the OpenAI SDK you already know, so existing summarization code drops right in.使い慣れた OpenAI SDK のままなので、既存の要約処理にそのまま組み込める。
USAGE

Change one line. 変えるのは 1 行だけ。

Point the official OpenAI SDK at your Mac, or stream audio from anything that can open a WebSocket. 公式の OpenAI SDK の接続先を Mac に向けるだけ。WebSocket を開けるものなら何からでも音声を流せます。

  • Any audio file.どんな音声ファイルでも。 wav, m4a, mp3, aiff, caf… whatever AVFoundation reads.wav・m4a・mp3・aiff・caf など、AVFoundation で読めるものなら何でも。
  • Dozens of languages.多くの言語に対応。 English, Japanese, German, French, Spanish, Korean, Chinese and more. macOS downloads each model the first time you use it.英語・日本語・ドイツ語・フランス語・スペイン語・韓国語・中国語など。各言語のモデルは初回に macOS が自動で入れます。
  • Any sample rate.サンプルレートは自由。 Send 16-bit mono PCM at the rate you have; Dictable API converts it.手元の 16bit モノラル PCM をそのまま送れば、Dictable API が変換します。
from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:8082/v1",  # ← the only change
    api_key="not-needed",
)

with open("meeting.m4a", "rb") as f:
    result = client.audio.transcriptions.create(
        model="apple-on-device",
        file=f,
        language="ja",
        response_format="verbose_json",
    )

for s in result.segments:
    print(f"[{s.start:6.2f}s] {s.text}")
# Transcribe a file (OpenAI-compatible)
curl http://127.0.0.1:8082/v1/audio/transcriptions \
  -F file=@talk.m4a \
  -F language=en \
  -F response_format=srt

# Which languages are ready on this Mac?
curl http://127.0.0.1:8082/v1/locales
const ws = new WebSocket("ws://127.0.0.1:8082/v1/stream");
ws.binaryType = "arraybuffer";

ws.onmessage = ({ data }) => {
  const msg = JSON.parse(data);
  if (msg.type === "hello")
    ws.send(JSON.stringify({ type: "start", language: "en-US", sample_rate: 16000 }));
  if (msg.type === "partial") showDraft(msg.text);   // while speaking
  if (msg.type === "final")   addLine(msg.text);     // sentence done
};

// then: ws.send(int16Pcm.buffer) every ~100 ms

INSTALL

Running in a minute1 分で動かせます

Requires macOS 26 (Tahoe) or later on Apple silicon. macOS 26（Tahoe）以降、Apple シリコンの Mac が必要です。

Downloadダウンロード

Get the latest DictableAPI.zip from GitHub Releases and unzip it.GitHub の Releases から最新の zip を入手して展開します。

Move & open移動して開く

Drag Dictable API.app to Applications and double-click it. It is signed with a Developer ID and notarized by Apple, so it opens without warnings.Dictable API.app をアプリケーションフォルダへ移して、ダブルクリックで開きます。Developer ID で署名し、Apple の公証を受けているので、警告なしで開けます。

FAQ

Questionsよくある質問

Is it really free?本当に無料ですか？

Yes. Dictable API is free to download and use, with no account, no API key, and no usage limits. Recognition runs on your Mac with the speech model built into macOS, so there is no per-minute cost like a cloud API. The source code is MIT-licensed, so you can also use it in commercial projects.はい。ダウンロードも利用も無料で、登録・API キー・利用回数の制限もありません。認識は macOS に入っている音声モデルを使って Mac の中で行うので、クラウドの API のように使った時間に応じた料金もかかりません。ソースコードは MIT ライセンスなので、商用のプロジェクトにも使えます。

Does any audio leave my Mac?音声が Mac の外に送られることはありますか？

No. Recognition uses the on-device model, and the server only listens on 127.0.0.1. The only network traffic is macOS downloading a language model the first time you use that language.ありません。認識は Mac 内のモデルで行い、サーバーは 127.0.0.1 でしか待ち受けません。通信が発生するのは、ある言語を初めて使うときに macOS がモデルをダウンロードする場合だけです。

How does it compare to Whisper?Whisper と比べてどうですか？

Accuracy is similar for everyday speech. Dictable API is much faster on a laptop, has nothing to download or tune, and streams partial results natively. Whisper can auto-detect the language; Dictable API needs you to pass one.日常の会話なら精度は同程度です。ノート PC では Dictable API の方がずっと速く、モデルの準備や調整も要らず、話している途中の結果も最初から出せます。言語の自動判定は Whisper にしかなく、Dictable API では言語の指定が必要です。

Can websites I visit use it?閲覧中の Web サイトから使われる心配は？

No. Requests must carry a loopback Host header, and browser requests are accepted only from extensions and localhost pages.ありません。Host ヘッダーが localhost であることを確認し、ブラウザからのリクエストは拡張機能と localhost のページからのものしか受け付けません。

The port 8082 is already taken.8082 番ポートが他のアプリと重なります。

Dictable API detects the clash and offers the next free port in one click. You can also set any port under Settings.Dictable API が重なりを検知して、空いているポートをワンクリックで提案します。Settings で好きな番号に変えることもできます。

Is the app safe to open?アプリは安全に開けますか？

Yes. Releases are signed with a Developer ID and notarized by Apple, which scans them for malware, so macOS opens them without warnings. The full source is on GitHub, and you can build it yourself with ./scripts/build-app.sh.はい。配布しているアプリは Developer ID で署名し、マルウェアの検査を含む Apple の公証を受けているので、macOS は警告なしで開きます。ソースコードはすべて GitHub で公開していて、./scripts/build-app.sh で自分でビルドすることもできます。
